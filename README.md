# Le Cimetière du Sprint

Onepage pixel art pour choisir le film d'horreur de la soirée, façon poker planning.

- TV : `https://cvillemus.github.io/cimetiere-du-sprint/`
- Vote (téléphones) : `https://cvillemus.github.io/cimetiere-du-sprint/vote`

## Démarrer

```bash
npm install
npm start
```

## Déploiement

Chaque push sur `main` déclenche le workflow GitHub Actions qui teste, construit et publie sur GitHub Pages.
